# 复合固件职责与资源归属

本页保留设计约束，不作为当前全部功能已完成验证的声明。

## 建议的职责与资源归属

| 资源/功能 | 所有者 | 其他核心如何使用 |
| --- | --- | --- |
| PSRAM 配置 | 主核启动阶段，一次性完成 | 初始化完成后再启动副核 |
| 双缓冲显存、MIPI、VDMA、显示中断 | 副核 | 主核只发布视图数据，不写显存 |
| GT911、运行期 I2C1 | 副核 | 音频若需运行期 codec 配置，发送请求给所有者 |
| USB 控制器、HID/VIA、UAC1 | 主核 | 副核发送按键事件，读取 USB 状态 |
| I2S/DMA 与音频缓冲 | 主核 | UI 只发送控制命令，不接触样本缓冲 |
| C5 SDIO、Wi-Fi、BLE、网络栈、校时 | 主核 | 副核发扫描/连接请求，接收结果 |
| 键位配置与持久化 | 主核 | 副核使用带版本的配置快照 |

不把所有数据都塞入一个全局锁。最新状态（时间/IP/连接状态）允许覆盖；
扫描/连接请求使用有界命令队列并明确忙状态；按键释放不可静默丢弃，需要
溢出后的全释放/状态重同步策略。ISR 只确认中断、更新计数或唤醒任务。

## 启动与验证边界

主核初始化 PSRAM、静态缓冲及持久配置，配置 ES8311 后移交 I2C1 给副核。
显示副核持有帧缓冲及显示外设；跨核只交换状态快照与有界命令。
Flash 写入须先完成双核停驻与恢复协议，避免另一核心同时从 Flash 取指。

显示与无线共存已完成独立验证，见 [共存验证](COEXIST_VERIFY.md)。
独立路径通过不能代替 USB、音频、无线、触摸同时工作的完整回归；
缓存持锁时间对实时性及长期音频稳定性的影响仍需验证。
